# 🌸 TG AutoResponder v1.0.1 (Pink & Black Edition)

Универсальный автоответчик для **Telegram** в стильном розово-черном дизайне с гибкой настройкой личных чатов!

---

## ✨ Что нового в v1.0.1:

- 👥 **Список чатов людей**: приложение перехватывает именно личные входящие сообщения людей (каналы и групповые чаты автоматически отфильтрованы).
- 💬 **Персональные ответы**: для любого человека можно задать индивидуальный текст ответа (или оставить стандартный).
- ⛔ **Отключение для отдельных контактов**: можно в один клик выключить автоответчик для конкретного человека.
- ➕ **Ручное добавление контактов**: возможность заранее добавить контакт по имени и настроить для него ответ.
- 🌸 **Стиль Pink & Black**: неоновый розово-черный киберпанк интерфейс на Jetpack Compose + Material 3.
- 📱 **Подписанный релизный APK**: `app-release.apk` с цифровым сертификатом безопасности.

## 📱 Как пользоваться вкладкой «Чаты и люди» на телефоне:

1. Откройте приложение и выдайте доступ к уведомлениям.
2. Включите главный тумблер **«Автоответчик ВКЛЮЧЕН»**.
3. Изначально автоответ работает **для всех личных чатов** стандартным текстом.
4. Перейдите во вкладку **«Чаты и люди»**:
   - Там отобразятся люди, которые вам пишут.
   - Нажмите **✏️ Редактировать** у любого контакта, чтобы ввести для него **индивидуальный ответ** или отключить ответы для него.
   - Либо нажмите **«+ Контакт»**, чтобы заранее добавить человека по имени из Telegram.
